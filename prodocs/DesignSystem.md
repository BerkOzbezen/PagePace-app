# Design System

## Renk Paleti
- Primary: #6C63FF (mor-mavi)
- Success: #4CAF50 (yeşil)
- Warning: #FF9800 (turuncu)
- Error: #F44336 (kırmızı)
- Background: #F8F9FA (açık gri)
- Surface: #FFFFFF (beyaz)
- Text Primary: #1A1A2E (koyu lacivert)
- Text Secondary: #6B7280 (gri)

## Tipografi
- H1: 32px, Bold
- H2: 24px, SemiBold
- H3: 18px, SemiBold
- Body: 14px, Regular
- Body Small: 12px, Regular

## Component Kuralları
- PPButton: primary/secondary/outlined varyantlar
- PPCard: 12px border radius, subtle shadow
- PPTextField: outlined style, prefix icon
- PPBookCard: kapak görseli + ilerleme çubuğu
- PPBookCover: Image.network + renk placeholder fallback

## Dark Mode
- ThemeMode.system varsayılan
- SharedPreferences ile tercih kaydedilir
